The standalone auditor now immediately saves each successful raw RPC response under a hash of its endpoint and exact request inputs, with the original fetch timestamp. It writes an atomic `<audit>.reads.json` checkpoint after every successful/cached read or failure, so a later failed Market read retains the fetched config bytes. Default reuse is bounded to **300 seconds**; `--cache-max-age-seconds 0` forces fresh reads, and the maximum permitted reuse is one hour. The final report retains every read’s fetch time/cache age and both context slots. Expired entries are refreshed; exhausted reads remain gaps. The cache is bounded to 32 responses / 64 MiB with a 16 MiB per-response cap. `oracle-cache-test.py` verifies resume, raw-byte retention, forced refresh, expiry and bounded retry failure without network access.
